### 关键坑（重要，可复用）
1. **npm 全局包的依赖文件是只读属性**，GNU `rm`（含 `/usr/bin/rm`）删除时报 `Permission denied`。两种解法：
   - 用 `npm uninstall -g <pkg>`（npm 内部正确处理只读）
   - 或先 `attrib -r -s -h "dir\*" /s /d` 清只读，再 `rd /s /q`
2. 删 `~/.dsh` 时 `profiles/web/node_modules/rxjs` 等同样只读，最终靠 `.bat` 里 `attrib -r -s -h` + `rd /s /q` 搞定。
3. **PowerShell 工具 stdout 不回显**（Write-Output 看不到），要拿结果就写到文件再 Read，或靠退出码判断。

## ChatGPT Plus Codex 连不上（request timed out）

用户购买了 ChatGPT Plus，用 Codex（ChatGPT 网页/桌面内）一直"正在重新连接 /5 + request timed out"。

### 诊断结论
- 用户代理是 **BeiBei**（`BeiBeiCore.exe`，`AppData\Local\Programs\BeiBei\`，监听混合端口 **7892**）。
- 代理能翻墙：google 返回 302 ✅。
- 但 OpenAI/ChatGPT 域名通过代理**全部超时**：chatgpt.com、ab.chatgpt.com、auth.openai.com 都是 HTTP 000（超时）；api.openai.com 能连但返回 401。
- 相关域名 DNS 被污染（chatgpt.com 解析到 173.236.212.42 等错误 IP）。

### 结论
BeiBei 代理对 OpenAI/ChatGPT 流量支持有问题（分流规则或节点），导致 Codex 连不上。需换节点/开全局模式，或换通用代理（Clash Verge 等）。
